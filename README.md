# 浅听音乐格式转换器 v3.0.0

一个支持多种加密音频格式转换的桌面应用程序，采用模块化架构设计。

## 🚀 主要特性

- **模块化架构**: 采用现代化的模块化设计，易于维护和扩展
- **多格式支持**: 支持 KGM、NCM、QMC/OGG、WAV 等格式转换
- **工厂模式**: 使用工厂模式管理转换器，动态加载和扩展
- **配置管理**: 完整的配置管理系统，支持个性化设置
- **批量转换**: 支持单文件和批量文件转换
- **现代界面**: 基于 PyQt6 的现代化用户界面
- **进度显示**: 实时显示转换进度和状态
- **错误处理**: 完善的错误处理和日志记录

## 🔧 架构特点

### 模块化设计

- **核心模块**: 提供基础抽象类和工厂模式
- **转换器模块**: 独立的格式转换器实现
- **界面模块**: 分离的GUI组件
- **配置模块**: 集中的配置管理
- **工具模块**: 通用工具函数

### 设计模式

- **工厂模式**: 动态创建转换器实例
- **抽象基类**: 确保转换器接口一致性
- **观察者模式**: 进度回调和状态通知
- **单例模式**: 配置管理器

### 扩展性

- 新格式支持：只需实现 `AudioConverter` 基类
- 注册机制：自动发现和注册转换器
- 配置系统：支持新的配置项
- 界面组件：模块化的GUI组件

## 📝 开发指南

### 添加新的转换器

1. 在 `converters/` 目录创建新的转换器文件
2. 继承 `AudioConverter` 基类
3. 实现必需的抽象方法
4. 在 `core/registry.py` 中注册转换器

### 配置管理

- 配置文件位置：`~/.config/audioconverter/settings.json`
- 配置类：`config.settings.AppSettings`
- 加载和保存：使用 `config` 模块的函数

### 日志系统

- 日志文件：`logs/converter.log`
- 日志级别：DEBUG, INFO, WARNING, ERROR
- 配置：在设置中可调整日志级别
