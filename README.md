# 浅听音乐格式转换器 v3.0.0

一个专注于“加密音乐文件格式转换”的桌面应用。支持 KGM、NCM、QMC/OGG、WAV 等格式，转换到 MP3/FLAC，适合批量与单文件场景。界面简洁，操作直观，转换过程可视化并具备完善的错误处理与日志记录。

## ⚡ 快速启动（Windows PowerShell）

> 以下命令为 PowerShell 语法，复制到终端即可执行。

```powershell
# 1) 创建并激活虚拟环境（可选，但推荐）
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 2) 安装依赖
pip install -r requirements.txt

# 3) 启动程序
python .\main.py
```

说明：
- 首次启动会自动创建默认配置与日志目录。
- 在主界面中选择“单文件转换”或“批量转换”，导入待转换文件并开始转换。
- 点击工具栏“关于”可查看许可证与仓库链接。

## 🎯 支持格式

### 输入格式

| 格式 | 平台 | 说明 |
|------|------|------|
| KGM | 酷狗音乐 | 酷狗音乐加密格式 |
| NCM | 网易云音乐 | 网易云音乐加密格式 |
| QMC/OGG | QQ音乐 | QQ音乐加密格式 |
| WAV | 通用 | 无损音频格式 |
<!-- MFLAC 行已移除：新版不可转换，功能下线 -->

### 输出格式

- **MP3**: 通用压缩音频格式
- **FLAC**: 无损音频格式（部分转换器支持）

## 🔧 架构特点

### 模块化设计

- **核心模块**: 提供基础抽象类和工厂模式
- **转换器模块**: 独立的格式转换器实现
- **界面模块**: 分离的GUI组件
- **配置模块**: 集中的配置管理
- **工具模块**: 通用工具函数

### 设计模式

- **工厂模式**: 动态创建转换器实例
- **抽象基类**: 确保转换器接口一致性
- **观察者模式**: 进度回调和状态通知
- **单例模式**: 配置管理器

### 扩展性

- 新格式支持：只需实现 `AudioConverter` 基类
- 注册机制：自动发现和注册转换器
- 配置系统：支持新的配置项
- 界面组件：模块化的GUI组件

## 📝 开发指南

### 添加新的转换器

1. 在 `converters/` 目录创建新的转换器文件
2. 继承 `AudioConverter` 基类
3. 实现必需的抽象方法
4. 在 `core/registry.py` 中注册转换器

### 配置管理

- 配置文件位置：`~/.config/audioconverter/settings.json`
- 配置类：`config.settings.AppSettings`
- 加载和保存：使用 `config` 模块的函数

### 日志系统

- 日志文件：`logs/converter.log`
- 日志级别：DEBUG, INFO, WARNING, ERROR
- 配置：在设置中可调整日志级别
