浅听音乐格式转换器 v3.0.0 发布说明

发布日期：2025-11-28

重要变更：
- 移除 MFLAC 支持：由于 QQ 音乐新版加密不可转换，相关实现与 GUI 文案、文档已全部下线。
- 同步支持格式列表：当前支持 ncm、kgm、ogg（含 qmc/qmc0/qmc3/qmcflac）、wav。
- 清理测试与代码：删除 MFLAC 相关测试与实现文件，避免残留引用。

新增与改进：
- 稳定的转换器注册与工厂机制，统一日志与错误处理。
- GUI 文件筛选与“关于”说明同步刷新，避免用户误选不支持格式。

已知问题与建议：
- 本仓库自带的虚拟环境 myenv 指向不存在的 Python 路径，建议重建虚拟环境。
  PowerShell 示例：
  1) python -m venv .\myenv
  2) .\myenv\Scripts\pip.exe install -r .\requirements.txt

启动与使用：
- PowerShell 启动：python .\main.py
- 转换输出目录默认为项目根目录下的 output，可在设置中调整。

升级指南：
- 旧版本使用过 MFLAC 的用户，请移除输入目录中的 .mflac 文件；新版本不会再识别或显示该格式。
- 如遇启动异常，请先删除配置文件（%APPDATA%\AudioConverter\settings.json），再启动应用以生成新的默认配置。
==================

简介
----
音频格式转换器是一款简单易用的音频文件格式转换工具，支持将 KGM（酷狗音乐）和 NCM（网易云音乐）格式转换为通用的 MP3 或 FLAC 格式。软件采用现代界面设计，操作简单直观。

主要功能
--------
1. 支持格式转换：
   - KGM (酷狗音乐) → MP3/FLAC
   - NCM (网易云音乐) → MP3/FLAC

2. 界面特性：
   - 简洁美观的图形界面
   - 支持文件拖拽操作
   - 实时转换进度显示
   - 自定义输出目录
   - 已转换文件列表显示

3. 文件处理：
   - 保留音频元数据（歌手、专辑等信息）
   - 保持音频质量
   - 批量转换功能

系统要求
--------
- 操作系统：Windows 7/8/10/11
- 处理器：1.5GHz 及以上
- 内存：2GB 及以上
- 硬盘空间：100MB 以上可用空间

安装说明
--------
本软件为免安装版本，直接解压后运行即可使用。

使用方法
--------
1. 运行程序：
   双击运行"格式转换器.exe"

2. 选择格式：
   从下拉菜单中选择需要转换的文件格式（KGM 或 NCM）

3. 选择文件：
   - 方式一：点击"选择文件"按钮选择要转换的文件
   - 方式二：直接将文件拖拽到程序窗口

4. 设置输出：
   - 默认输出到程序所在目录下的 kgm-vpr-out 文件夹
   - 可点击"选择目录"自定义输出位置

5. 开始转换：
   点击"开始转换"按钮，等待转换完成

注意事项
--------
1. 使用提示：
   - 首次运行可能需要等待几秒钟
   - 转换过程中请勿关闭程序
   - 请确保有足够的磁盘空间

2. 重要说明：
   - 本软件仅供个人学习研究使用
   - 转换后的音频文件仅供试听
   - 请支持正版音乐，尊重知识产权
